Wirespec is a small language for describing APIs. You write the contract once, in a `.ws` file, and every side of the
API generates its own typesafe, dependency-free code from it: TypeScript for the frontend, Kotlin, Java, Python, Rust or
Scala for the backend, and OpenAPI or Avro for everyone else.

## Where do you want to start?

Pick the description that fits you best. Each guide gets you from nothing to working code in a few minutes, with the
tools you already use.

## What a contract looks like

The guides share one small contract: a todo API with three types and three endpoints. The frontend generates a client
from this file and the backend generates the handlers it implements, so both sides always agree on paths, bodies and
status codes.

```wirespec wirespec source
```

Every endpoint lists the responses it can return, and the generated code turns them into types: a client sees that
`GetTodo` can answer `404` with an `ApiError`, and a server can only return the status codes the contract defines.

## Something else?

- **Just looking around?** Edit Wirespec and see the generated code live in the
  [Playground](https://playground.wirespec.io), no installation needed, or read why Wirespec puts the
  [contract first](../intro/intro-contract.md).
- **Testing against an API?** Stub a Wirespec API in JVM tests with [WireMock](../integration/integration-wiremock.mdx),
  or in the browser and Node.js with [MSW](./frontend.mdx#mock-the-api). Generate test data that matches the contract
  with [Kotest](../integration/integration-kotest.mdx).
- **Extending Wirespec?** Learn how the compiler works in [Architecture](../architecture/architecture.md), change the
  generated code with [IR extensions](../plugins/plugins.md#ir-extensions), or connect an editor through the
  [Language Server](../ide/lsp.md).
- **Only need to install a tool?** Go straight to the [CLI](../plugins/plugins-cli.md), [npm](../plugins/plugins-npm.md),
  [Gradle](../plugins/plugins-gradle.md) or [Maven](../plugins/plugins-maven.md) plugin, or the [IDE plugins](../ide/ide.md).
