Wirespec has integrations with major frameworks, including Spring for enterprise application development, Jackson and
kotlinx.serialization for JSON processing, Avro for data serialization and schema management, WireMock for type-safe
HTTP stubbing in tests, and Kotest for property-based scenario tests driven by your contract. For the JVM languages it can
also add builders to the generated models.
