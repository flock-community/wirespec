Wirespec has integrations with major frameworks, including Spring for enterprise application development, Jackson and
kotlinx.serialization for JSON processing, Avro for data serialization and schema management, WireMock for type-safe
HTTP stubbing in tests, and Kotest for property-based scenario tests driven by your contract. For the JVM languages it can
also add builders to the generated models, and a typed GraphQL client for the rpcs of a GraphQL schema.

## Overview

| Integration                                                      | What it does                                                       | Languages                                             | Status       |

| [Avro](./integration-avro.mdx)                                   | Avro schemas and converters next to the models                     | <Languages languages={["Java", "Kotlin"]} />          | Experimental |

Every integration page starts with the languages it applies to. An integration marked **experimental** is ready to try,
but its API, generated code and options may still change between releases.
