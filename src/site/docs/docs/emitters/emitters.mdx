# Emitters

Wirespec generates functional and dependency-free code. The generated output consists of structs and functions.

## Structure

This diagram provides an overview of the generic structure of the code emitted by Wirespec. The same structure is consistently applied across all supported languages, with minor exceptions to leverage language-specific features when beneficial.

The structure exists of a shared part and a part per emitted output. The shared part holds interfaces of the Wirespec functional model. The specific part has models of all types, endpoints, channels and rpcs.

## Default values

Field [default values](../language/types.mdx#default-values) are generated where the target supports them:

| Emitter                                   | Default values                                                              |
|-------------------------------------------|-----------------------------------------------------------------------------|
| Kotlin                                    | Constructor parameter defaults, see the [Kotlin emitter](./emitters-kotlin.mdx#default-values) |
| Avro                                      | The `default` of the record field, see the [Avro emitter](./emitters-avro.mdx#default-values) |
| OpenAPI v2 and v3                         | The `default` of the property schema, see the [OpenAPI v3 emitter](./emitters-open-api-v3.mdx#default-values) |
| Wirespec                                  | `field: Type = value`                                                       |
| Java, TypeScript, Python, Rust and Scala  | Not supported yet, see the [Java emitter](./emitters-java.mdx#default-values) |
