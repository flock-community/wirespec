# Python Emitter

The Python emitter generates dataclasses, enums and abstract base classes that only depend on the Python standard
library. It needs Python 3.10 or newer. This page shows the code it generates for the
[Todo example](./emitters.mdx#the-example):

```shell
wirespec compile -i todo.ws -o out -l Python -p community.flock.todo --shared
```

```text
out
└── community/flock/todo
    ├── __init__.py
    ├── wirespec.py
    ├── Client.py
    ├── channel/TodoEvents.py
    ├── client/UpdateTodoClient.py, __init__.py
    ├── endpoint/UpdateTodo.py, __init__.py
    ├── generator/TodoGenerator.py, TodoIdGenerator.py, ...
    ├── model/Todo.py, TodoId.py, Priority.py, ..., __init__.py
    └── rpc/CompleteTodo.py
```

The `__init__.py` files turn the directories into packages, and `model/__init__.py` imports every model, so they can
be imported from `community.flock.todo.model`. Every file starts with the same block of standard library imports
followed by the imports it needs, which are left out of the examples below.

## Type

A type becomes a `@dataclass` that extends `Wirespec.Shape`:

```python title="model/Todo.py"
@dataclass
class Todo(Wirespec.Shape):
    id: TodoId
    title: str
    done: bool
    priority: Priority
    tags: list[str]
    dueDate: Optional[str]
    def validate(self) -> list[str]:
        return (['id'] if not self.id.validate() else [])
```

The fields map to Python types as follows:

| Wirespec               | Python           |
|------------------------|------------------|
| `String`               | `str`            |
| `Integer`, `Integer32` | `int`            |
| `Number`, `Number32`   | `float`          |
| `Boolean`              | `bool`           |
| `Bytes`                | `bytes`          |
| `T[]`                  | `list[T]`        |
| `{ T }`                | `dict[str, T]`   |
| `T?`                   | `Optional[T]`    |

`validate()` returns the names of the fields that do not hold a valid value. Only refined values can be invalid, so
`Todo` checks `id`. A type that contains another type passes on its errors with the field name as a prefix:

```python title="model/TodoCreated.py"
@dataclass
class TodoCreated(Wirespec.Shape, TodoEvent):
    todo: Todo
    def validate(self) -> list[str]:
        return [f"todo.{e}" for e in self.todo.validate()]
```

## Refined

A refined type becomes a `@dataclass` that wraps the value and extends `Wirespec.Refined`. `validate()` checks the
regular expression, and `str()` returns the plain value:

```python title="model/TodoId.py"
@dataclass
class TodoId(Wirespec.Refined[str]):
    value: str
    def validate(self) -> bool:
        return bool(re.match(r"^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$", self.value))
    def __str__(self) -> str:
        return self.value
```

A refined `Integer` or `Number` checks its bounds instead.

## Enum

An enum becomes an `enum.Enum` that also extends `Wirespec.Enum`. The value of every member is the value as it is
written in Wirespec:

```python title="model/Priority.py"
class Priority(Wirespec.Enum, enum.Enum):
    LOW = "LOW"
    MEDIUM = "MEDIUM"
    HIGH = "HIGH"
```

## Union

A union becomes a base class:

```python title="model/TodoEvent.py"
class TodoEvent:
    pass
```

Every member of the union extends it, as `TodoCreated` above does with `(Wirespec.Shape, TodoEvent)`, so
`isinstance(event, TodoEvent)` holds for both members.

## Endpoint

An endpoint becomes a module that holds everything that is needed to send and receive the request and its responses.

### Request

The path parameters, query parameters and request headers each get a dataclass. `Request` combines them with the
method and the body. Its constructor takes all values as flat parameters:

```python title="endpoint/UpdateTodo.py"
@dataclass
class Path(Wirespec.Path):
    id: TodoId
@dataclass
class Queries(Wirespec.Queries):
    notify: Optional[bool]
@dataclass
class RequestHeaders(Wirespec.Request.Headers):
    requestId: str
@dataclass
class Request(Wirespec.Request[TodoInput]):
    path: Path
    method: Wirespec.Method
    queries: Queries
    headers: RequestHeaders
    body: TodoInput
    def __init__(
        self,
        id: TodoId,
        notify: Optional[bool],
        requestId: str,
        body: TodoInput,
    ):
        self.path = Path(id=id)
        self.method = Wirespec.Method.PUT
        self.queries = Queries(notify=notify)
        self.headers = RequestHeaders(requestId=requestId)
        self.body = body
```

### Responses

Every status code gets a response class, with a dataclass for its headers. The response classes are grouped by base
classes: `Response` for all of them, `Response2XX` and `Response4XX` per status class, and `ResponseTodo` and
`ResponseApiError` per body type:

```python title="endpoint/UpdateTodo.py"
class Response(Wirespec.Response[T], Generic[T]):
    pass
class Response2XX(Response[T], Generic[T]):
    pass
class Response4XX(Response[T], Generic[T]):
    pass
class ResponseTodo(Response[Todo]):
    pass
class ResponseApiError(Response[ApiError]):
    pass
@dataclass
class Response200Headers(Wirespec.Response.Headers):
    version: int
@dataclass
class Response200(Response2XX[Todo], ResponseTodo):
    status: int
    headers: Response200Headers
    body: Todo
    def __init__(
        self,
        version: int,
        body: Todo,
    ):
        self.status = 200
        self.headers = Response200Headers(version=version)
        self.body = body
@dataclass
class Response404Headers(Wirespec.Response.Headers):
    pass
@dataclass
class Response404(Response4XX[ApiError], ResponseApiError):
    status: int
    headers: Response404Headers
    body: ApiError
    def __init__(
        self,
        body: ApiError,
    ):
        self.status = 404
        self.headers = Response404Headers()
        self.body = body
```

### Serialization

The class `UpdateTodo` has four static methods that convert between the typed request and response and the
`Wirespec.RawRequest` and `Wirespec.RawResponse` that go over the wire. They delegate the serialization of the path,
parameters, headers and body to a `Wirespec.Serializer` or `Wirespec.Deserializer`:

```python title="endpoint/UpdateTodo.py"
class UpdateTodo(Wirespec.Endpoint):
    @staticmethod
    def toRawRequest(serialization: Wirespec.Serializer, request: Request) -> Wirespec.RawRequest:
        return Wirespec.RawRequest(method=request.method.value, path=['todos', serialization.serializePath(request.path.id, TodoId)], queries={'notify': (serialization.serializeParam(request.queries.notify, bool) if request.queries.notify is not None else [])}, headers={'requestId': serialization.serializeParam(request.headers.requestId, str)}, body=serialization.serializeBody(request.body, TodoInput))
    # ...
```

`fromRawRequest`, `toRawResponse` and `fromRawResponse` work the same way.

### Handler and Call

`UpdateTodo.Handler` is the abstract class the server implements, `UpdateTodo.Call` is the abstract class the client
implements:

```python title="endpoint/UpdateTodo.py"
    class Handler(Wirespec.Handler, ABC):
        @abstractmethod
        async def update_todo(self, request: Request) -> Response[Any]:
            ...
    class Call(Wirespec.Call, ABC):
        @abstractmethod
        async def update_todo(self, id: TodoId, notify: Optional[bool], requestId: str, body: TodoInput) -> Response[Any]:
            ...
```

## Channel

A channel becomes a class with a `Sender` to publish messages and a `Listener` to receive them:

```python title="channel/TodoEvents.py"
class TodoEvents(Wirespec.Channel):
    class Sender(ABC):
        @abstractmethod
        def TodoEvents(self, message: TodoEvent) -> None:
            ...
    class Listener(ABC):
        @abstractmethod
        def TodoEvents(self, handler: Callable[[TodoEvent], None]) -> None:
            ...
```

## RPC

An RPC becomes a class with a `Service` to implement. Because `CompleteTodo` declares an error, the service returns a
`Response` that is either a `Result` or an `Error`. Without an error, it returns the result type directly:

```python title="rpc/CompleteTodo.py"
class CompleteTodo(Wirespec.Rpc):
    class Response:
        pass
    @dataclass
    class Result(Response):
        value: Todo
    @dataclass
    class Error(Response):
        value: ApiError
    class Service(ABC):
        @abstractmethod
        async def CompleteTodo(self, id: TodoId) -> CompleteTodo.Response:
            ...
```

## Client

For every endpoint, a client implements its `Call` class. It builds the `Request`, converts it with `toRawRequest`,
sends it with a `Wirespec.Transportation` and converts the answer with `fromRawResponse`:

```python title="client/UpdateTodoClient.py"
@dataclass
class UpdateTodoClient(UpdateTodo.Call):
    serialization: Wirespec.Serialization
    transportation: Wirespec.Transportation
    async def update_todo(self, id: TodoId, notify: Optional[bool], requestId: str, body: TodoInput) -> Response[Any]:
        request = Request(id=id, notify=notify, requestId=requestId, body=body)
        rawRequest = UpdateTodo.toRawRequest(serialization=self.serialization, request=request)
        rawResponse = await self.transportation.transport(rawRequest)
        return UpdateTodo.fromRawResponse(serialization=self.serialization, response=rawResponse)
```

`Client` implements the `Call` class of every endpoint in the specification, so one instance can call the whole API:

```python title="Client.py"
@dataclass
class Client(UpdateTodo.Call):
    serialization: Wirespec.Serialization
    transportation: Wirespec.Transportation
    async def update_todo(self, id: TodoId, notify: Optional[bool], requestId: str, body: TodoInput) -> Response[Any]:
        return await UpdateTodoClient(serialization=self.serialization, transportation=self.transportation).update_todo(id, notify, requestId, body)
```

## Generator

For every type, refined type, enum and union, a generator builds an instance with values from a `Wirespec.Generator`.
It passes the path to the field and a description of the value it needs, such as the regular expression of a refined
type. This is how you create test data that matches the specification:

```python title="generator/TodoIdGenerator.py"
class TodoIdGenerator:
    @staticmethod
    def generate(generator: Wirespec.Generator, path: list[str]) -> TodoId:
        return TodoId(value=generator.generate(path + ['value'], Wirespec.GeneratorFieldString(regex='^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$', annotations=[])))
```

## Shared

`wirespec.py` is the same for every specification. Its `Wirespec` class contains:

| Declarations                                                                 | Purpose                                                       |
|------------------------------------------------------------------------------|---------------------------------------------------------------|
| `Model`, `Shape`, `Enum`, `Refined`                                          | Extended by the generated types, enums and refined types      |
| `Endpoint`, `Channel`, `Rpc`, `Handler`, `Call`                              | Extended by the generated endpoints, channels and RPCs        |
| `Method`, `Request`, `Response`, `Path`, `Queries`, `Headers`                | The typed request and response of an endpoint                 |
| `Serializer`, `Deserializer`, `Serialization` and their parts                | Plug in the serialization of bodies, paths and parameters     |
| `RawRequest`, `RawResponse`, `Transportation`                                | The untyped request and response, and how to send them        |
| `Generator`, `GeneratorField` and its subclasses                             | Generate values for the generators                            |

import enum
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Any, Callable, Generic, Optional, Type, TypeVar
T = TypeVar('T')
V = TypeVar('V')
def _raise(msg: str) -> Any:
    raise Exception(msg)

class Wirespec:
    class Model(ABC):
        pass
    class Shape(Model, ABC):
        @abstractmethod
        def validate(self) -> list[str]:
            ...

        label: str
    class Refined(Model, ABC, Generic[T]):
        value: T
        @abstractmethod
        def validate(self) -> bool:
            ...

        pass
    class Channel(ABC):
        pass
    class Rpc(ABC):
        pass
    class Path(ABC):
        pass
    class Queries(ABC):
        pass
    class Headers(ABC):
        pass
    class Handler(ABC):
        pass
    class Call(ABC):
        pass
    class Method(enum.Enum):
        GET = "GET"
        PUT = "PUT"
        POST = "POST"
        DELETE = "DELETE"
        OPTIONS = "OPTIONS"
        HEAD = "HEAD"
        PATCH = "PATCH"
        TRACE = "TRACE"
    class Request(ABC, Generic[T]):
        path: Wirespec.Path
        method: Wirespec.Method
        queries: Wirespec.Queries
        headers: Headers
        body: T
        class Headers(ABC):
            pass
    class Response(ABC, Generic[T]):
        status: int
        headers: Headers
        body: T
        class Headers(ABC):
            pass
    class BodySerializer(ABC):
        @abstractmethod
        def serializeBody(self, t: T, type: type[T]) -> bytes:
            ...
    class BodyDeserializer(ABC):
        @abstractmethod
        def deserializeBody(self, raw: bytes, type: type[T]) -> T:
            ...
    class BodySerialization(BodySerializer, BodyDeserializer, ABC):
        pass
    class PathSerializer(ABC):
        @abstractmethod
        def serializePath(self, t: T, type: type[T]) -> str:
            ...
    class PathDeserializer(ABC):
        @abstractmethod
        def deserializePath(self, raw: str, type: type[T]) -> T:
            ...
    class PathSerialization(PathSerializer, PathDeserializer, ABC):
        pass
    class ParamSerializer(ABC):
        @abstractmethod
        def serializeParam(self, value: T, type: type[T]) -> list[str]:
            ...
    class ParamDeserializer(ABC):
        @abstractmethod
        def deserializeParam(self, values: list[str], type: type[T]) -> T:
            ...
    class ParamSerialization(ParamSerializer, ParamDeserializer, ABC):
        pass
    class Serializer(BodySerializer, PathSerializer, ParamSerializer, ABC):
        pass
    class Deserializer(BodyDeserializer, PathDeserializer, ParamDeserializer, ABC):
        pass
    class Serialization(Serializer, Deserializer, ABC):
        pass
    @dataclass
    class RawRequest:
        method: str
        path: list[str]
        queries: dict[str, list[str]]
        headers: dict[str, list[str]]
        body: Optional[bytes]
    @dataclass
    class RawResponse:
        statusCode: int
        headers: dict[str, list[str]]
        body: Optional[bytes]
    class Transportation(ABC):
        @abstractmethod
        async def transport(self, request: Wirespec.RawRequest) -> Wirespec.RawResponse:
            ...
    class GeneratorField(ABC, Generic[T]):
        pass
    @dataclass
    class GeneratorFieldString(GeneratorField[str]):
        regex: Optional[str]
        annotations: list[dict[str, Any]]
    @dataclass
    class GeneratorFieldInteger64(GeneratorField[int]):
        min: Optional[int]
        max: Optional[int]
        annotations: list[dict[str, Any]]
    @dataclass
    class GeneratorFieldInteger32(GeneratorField[int]):
        min: Optional[int]
        max: Optional[int]
        annotations: list[dict[str, Any]]
    @dataclass
    class GeneratorFieldNumber64(GeneratorField[float]):
        min: Optional[float]
        max: Optional[float]
        annotations: list[dict[str, Any]]
    @dataclass
    class GeneratorFieldNumber32(GeneratorField[float]):
        min: Optional[float]
        max: Optional[float]
        annotations: list[dict[str, Any]]
    @dataclass
    class GeneratorFieldBoolean(GeneratorField[bool]):
        annotations: list[dict[str, Any]]
    @dataclass
    class GeneratorFieldBytes(GeneratorField[bytes]):
        annotations: list[dict[str, Any]]
    @dataclass
    class GeneratorFieldEnum(GeneratorField[str]):
        values: list[str]
        annotations: list[dict[str, Any]]
        type: type[Any]
    @dataclass
    class GeneratorFieldUnion(GeneratorField[str]):

        annotations: list[dict[str, Any]]

## Default values

The Python emitter does not support [default values](../language/types.mdx#default-values) yet. Compiling the
[defaults from the example](./emitters.mdx#default-values) to Python fails, and the error names the fields that have
one:

```
Python does not support default values, but these fields have one: Todo.done, Todo.priority, Todo.dueDate. Remove the
defaults, or leave them out of the generated code with the ignore defaults option: --ignore-defaults for the CLI, or
ignoreDefaults in the Gradle and Maven plugins.
```

To generate Python anyway, leave the defaults out with the [ignore defaults option](../language/types.mdx#ignoring-defaults):

```shell
wirespec compile -i todo.ws -o out -l Python -p community.flock.todo --ignore-defaults
```

A [conversion](../converters/converters.md) from OpenAPI or Avro to Python does not fail: it leaves the defaults out.
