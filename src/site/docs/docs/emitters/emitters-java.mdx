## Default values

The Java emitter does not support [default values](../language/types.mdx#default-values) yet. Compiling a spec with
defaults to Java fails, and the error names the fields that have one:

```
Java does not support default values, but these fields have one: Settings.name, Settings.retries. Remove the defaults,
or leave them out of the generated code with the ignore defaults option: --ignore-defaults for the CLI, or
ignoreDefaults in the Gradle and Maven plugins.
```

To generate Java anyway, leave the defaults out with the [ignore defaults option](../language/types.mdx#ignoring-defaults):

```shell
wirespec compile -i ./wirespec -l Java --ignore-defaults
```

A [conversion](../converters/converters.md) from OpenAPI or Avro to Java does not fail: it leaves the defaults out.
